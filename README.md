# Sales-Data-Visualization

# This project performs retail sales data analysis and visualization using Python.
# It uses Pandas for data processing and Matplotlib/Seaborn for creating insightful visualizations.
# The analysis includes daily sales trends, sales by product category and gender, and customer age distribution.
# Additional insights are shown using pie charts and heatmaps to understand sales contribution across age groups and product categories.
# The project helps in identifying customer behavior and sales patterns from the provided CSV dataset.
